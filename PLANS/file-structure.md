## Where code goes

|           Location          |                               What goes there                                |
| :-------------------------: | :--------------------------------------------------------------------------: |
|          `src/app/`         |                 Pages that load data and arrange components                  |
|        `src/actions/`       |                 Changes to data, with input validated first                  |
|          `src/lib/`         |    Calculations and external services, kept separate so they're testable     |
|        `loading.tsx`        | Placeholder in each route that reads an ID from the URL, as Next.js requires |
| `src/lib/supabase/admin.ts` |  Service-role access, which only server code can use, like all secret keys   |
